# ☁️ Free-Tier Deployment Guide (Zero Cost)

Because **Gen-AI Studio** uses Stable Diffusion, it strictly requires a GPU (ideally 12GB+ VRAM) to generate images quickly. Standard free server tiers (like AWS EC2 Micro or Render free tier) only offer small CPUs, meaning an image would take 5–10 minutes to generate, which ruins the demo experience.

Below is the definitive path to deploying your project perfectly for **Free ($0)** using **Google Colab**. 

## Why Google Colab?
- Offers a **Free Tesla T4 GPU (16GB VRAM)**.
- Can run FastAPI, MLflow, and Streamlit directly inside a single notebook cell.
- Uses `ngrok` to punch a public URL tunnel directly to your Streamlit UI, so you can present it from anywhere seamlessly.

---

## 🛠️ Deployment Steps (5 Minutes)

### 1. Create the Notebook
Log in to your Google Account, go to [Google Colab](https://colab.research.google.com/), and click **"New Notebook"**.

Go to **Runtime > Change runtime type** and select **T4 GPU** as the hardware accelerator.

### 2. Paste the Setup Script
In the first cell, paste this code. It clones your project (if you pushed it to GitHub), installs the dependencies, and downloads the `ngrok` executable.

```bash
# Clone your project (replace with your repo URL, or just zip up and upload your 'dlops_project' folder)
!git clone https://github.com/YOUR_USERNAME/genai-studio.git
%cd genai-studio

# Install heavy requirements
!pip install -r requirements.txt
!pip install pyngrok

# Setup Ngrok Token (You need a free ngrok.com account and auth token)
!ngrok config add-authtoken YOUR_NGROK_AUTH_TOKEN_HERE
```

### 3. Run the Backend (FastAPI)
In the second cell, start the API engine in the background:

```python
import os
import subprocess
import time

# Create a dummy .env since there's no server environment
with open('.env', 'w') as f:
    f.write('HF_TOKEN=your_hugging_face_token_if_needed\n')

print("Starting FastAPI Backend...")
# Starts FastAPI using subprocess so we don't block the notebook
subprocess.Popen(["python", "-m", "uvicorn", "src.main:app", "--host", "0.0.0.0", "--port", "8000"])

time.sleep(15) # Wait for model to load into Colab's VRAM
print("Backend is Online!")
```

### 4. Run the Frontend & Public Tunnel (Streamlit)
In the final cell, start Streamlit alongside Ngrok. This will output a blue clickable link.

```python
from pyngrok import ngrok
print("Starting Streamlit Frontend...")
subprocess.Popen(["streamlit", "run", "src/app.py", "--server.port", "8501", "--server.address", "0.0.0.0"])

time.sleep(5)
# Expose Streamlit to the internet
public_url = ngrok.connect(8501)
print(f"\\n\\n🚀 YOUR DEMO URL: {public_url}\\n\\n")
```

## 👨‍🏫 Presentation Day Workflow

1. Open your Colab Notebook.
2. Ensure you have the **T4 GPU** selected.
3. Run all cells from top to bottom.
4. Click the `ngrok.io` link generated by the final cell.
5. Present the beautiful, fast, GPU-accelerated application to your professor without spending a single dime on AWS!
