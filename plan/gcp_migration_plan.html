local
One environment (local)
No staging/prod split
→
GCP · medium effort
staging namespace + prod namespace in GKE
Promote image SHA from staging → prod via Cloud Build approval step
cloudbuild.yaml (the key file)
Pipeline in 4 steps: (1) docker build -t REGION-docker.pkg.dev/PROJECT/genai/backend:$COMMIT_SHA . — (2) docker push to Artifact Registry — (3) pytest src/tests/ + curl /health — (4) kubectl set image deployment/backend backend=IMAGE:SHA — done. The whole pipeline runs in ~4 minutes on a Cloud Build n1-standard-4.
